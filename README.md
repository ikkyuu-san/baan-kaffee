# Baan Kaffee

Baan Kaffee is a modern, responsive frontend website for a fictional coffee bar and Thai kitchen in Bangkok. It uses a dark, editorial-inspired design with warm accent colors, smooth scrolling, and simple entrance animations.

## Main Features

- Responsive layout for mobile, tablet, and desktop
- Dark modern cafe-inspired visual design
- Navigation bar with mobile menu
- Hero section with call-to-action button
- Menu cards with food and drink descriptions and prices
- About/story section
- Image gallery
- Contact details and opening hours
- Smooth scrolling between sections
- Simple scroll reveal animations
- Custom favicon and page metadata

## Technologies Used

- React
- Vite
- JavaScript (JSX)
- CSS
- Google Fonts
- Unsplash placeholder images

## How to Run Locally

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the website

Visit the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

### Build for production

```bash
npm run build
```
